# Examples
This section contains a number of example SGCT files showing off some of the capabilities of SGCT. Check the `config` folder in SGCT for more examples. Each example has a small description, the configuration file, and an image from the [Calibrator](/docs/building/calibrator) application using that configuration file. These examples are meant both as working example files that can be used, but also as an inspiration to create custom configuration files.
