# Contributing
Contributions to SGCT can come in many forms. From providing source code to fix bugs or add new features, adding a new warping mesh standard, or improving this documentation.

SGCT is split into two main repositories, the source code lives at [https://github.com/SGCT/SGCT](https://github.com/SGCT/SGCT) and the documentation is located at [https://github.com/SGCT/sgct.dev](https://github.com/SGCT/sgct.dev). Both repositories use GitHub issues and pull requests, so these are the best places to look first if you want to contribute but don't know what needs doing.

## Coding Style
The coding style of the SGCT repository uses the same that [OpenSpace](https://openspaceproject.com) uses: [source code](https://docs.openspaceproject.com/latest/contribute/development/coding-style.html) and [shader code](https://docs.openspaceproject.com/latest/contribute/development/glsl.html).
