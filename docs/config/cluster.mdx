# Cluster

The `Cluster` is the root object of every configuration file. It describes the entire cluster.

## Parameters

<Parameter name="version" type="integer">
The version of this configuration file. The current version number is `1`.
</Parameter>

<Parameter name="masteraddress" type="string">
Contains the address of the node that acts as the server for this cluster. This means that one of the [Node](node) elements described in this configuration file has to have an address that corresponds to this `masteraddress`. This value can be either an IP address or a DNS name, which will be resolved at application startup.
</Parameter>

<Parameter name="nodes" type={<><Link to="/docs/config/node">Node</Link>[]</>} optional>
Each object in this array has to be a valid [Node](node). At least one of the described nodes has to have an address that matches the cluster's `masteraddress`.
</Parameter>

<Parameter name="users" type={<><Link to="/docs/config/user">User</Link>[]</>} optional>
Each object in this array has to be a valid [User](user). The first value in the array is considered to be the default user for the application.
</Parameter>

<Parameter name="debuglog" type="boolean" optional defaultValue="false">
Determines whether the logging should include `Debug` level log messages. By default only `Info` level log messages or above are added to the console, the file, or the registered callback. Log messages that are not logged are discarded.
</Parameter>

<Parameter name="firmsync" type="boolean" optional defaultValue="false">
Determines whether the server should frame lock and wait for all client nodes or not. It is also possible, and more advisable, to set the frame locking on an individual [Node](node) basis for the cases where not all nodes are part of a swap group.
</Parameter>

<Parameter name="threadaffinity" type="integer" optional>
Forces the thread affinity for the main thread of the application. On Windows this is achieved using the `SetThreadAffinityMask` function, but it might not be implemented on other operating systems. By default no thread affinity is set for the application.
</Parameter>

<Parameter name="scene" type="Object" optional>
  Determines an overall orientation of the scene. All of its values are included in the projection matrix that is passed to the rendering function of the application.

  <Parameter name="offset" type={<Link to="/docs/config/basetypes">vec3</Link>} optional defaultValue="0, 0, 0">
  A linear offset of the scene center.
  </Parameter>

  <Parameter name="orientation" type="Object" optional>
  Describes a fixed orientation of the global scene.
  </Parameter>

  <Parameter name="scale" type="number" optional defaultValue="1.0">
  A scaling factor for the entire scene.
  </Parameter>

</Parameter>

<Parameter name="capture" type={<Link to="/docs/config/capture">Capture</Link>} optional>
Provides attributes that describe how the application will treat screen captures.
</Parameter>

<Parameter name="settings" type={<Link to="/docs/config/settings">Settings</Link>} optional>
Describes general settings for the application. The scene-specific settings can be found under the `scene` entry instead.
</Parameter>

<Parameter name="trackers" type={<><Link to="/docs/config/tracker">Tracker</Link>[]</>} optional>
Each object in this array describes a VRPN tracker.
</Parameter>

<Parameter name="generator" type="Object" optional>
  Information about the generator application that was used to create this configuration file.

  <Parameter name="name" type="string">A human-friendly name for the generator that created this configuration file.</Parameter>

  <Parameter name="major" type="integer">The major version of the generator that created this configuration file.</Parameter>

  <Parameter name="minor" type="integer">The minor version of the generator that created this configuration file.</Parameter>
</Parameter>

<Parameter name="meta" type="Object" optional>
  Information and description of the configuration file.

  <Parameter name="name" type="string">Name of the window configuration.</Parameter>

  <Parameter name="description" type="string">Description of the window configuration.</Parameter>

  <Parameter name="author" type="string" optional documentation="Author's name." />

  <Parameter name="license" type="string" optional documentation="Details of the software license." />

  <Parameter name="version" type="string" optional documentation="Version number of the configuration meta." />
</Parameter>
