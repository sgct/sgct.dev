# Base Types
The types in this file are considered base types in the sense that are reused among many types in the configuration files.

## ivec2
A type that represents a two-vector only accepting integer values.

## color
A type that represents a color value that is represented by four numerical values for the `r`ed, `g`reen, `b`lue, and `a`lpha channels as floating point numbers.

<Parameter name="r" type="number" />
<Parameter name="g" type="number" />

## mat4
A list of 16 floating-point numbers that represent a generic 4x4 matrix.

## Orientation
These two types represent orientations. Regardless of how they are expressed, they can be used interchangably.

### Yaw/Pitch/Roll
Represents an orientation as a collection of Euler angles in `yaw`, `pitch`, and `roll`. These will always be provided in degrees, not radians.

<Parameter name="pitch" type="number" />
<Parameter name="yaw" type="number" />
<Parameter name="roll" type="number" />

### Quaternion
Represents an orientation as a general quaternion with its `w`, `x`, `y`, and `z` components.

<Parameter name="x" type="number" />
<Parameter name="y" type="number" />
<Parameter name="z" type="number" />
<Parameter name="w" type="number" />

## Quality
Determines the pixel resolution of the cube map faces that are reprojected to create a non-linear projection. The higher resolution these cube map faces have, the better quality the resulting rendering, but at the expense of increased rendering times. The named values correspond to the following resolutions:

  - `low`: 256
  - `medium`: 512
  - `high`: 1024
  - `1k`: 1024
  - `1.5k`: 1536
  - `2k`: 2048
  - `4k`: 4096
  - `8k`: 8192
  - `16k`: 16384
  - `32k`: 32768
  - `64k`: 65536

Allowed values: `low`, `256`, `medium`, `512`, `high`, `1k`, `1024`, `1.5k`, `1536`, `2k`, `2048`, `4k`, `4096`, `8k`, `8192`, `16k`, `16384`, `32k`, `32768`, `64k`, `65536`
