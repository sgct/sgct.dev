# User
Specifies a user position and parameters. In most cases, only a single unnamed user is necessary. However, in more general cases, it is possible to assign users to specific [Viewports](viewport) to provide a more fine-grained control over the rendering that occurs in that viewport. The first user in the [Cluster](cluster)'s `users` array is the default user that is used by all viewports that do not specify a `user` of their own.

## Parameters
<Parameter name="name" type="string" optional default="default">
Specifies the name of this user, which is used by a viewport's `user` value to refer to this user. Each user needs to have a unique name, and at most one user can omit the name.
</Parameter>

<Parameter name="eyeseparation" type="number" optional default="0.06">
Determines the eye separation in meters used for stereoscopic viewports. If no viewports in the configuration are using stereo, this setting is ignored.
</Parameter>

<Parameter name="pos" type={<Link to="/docs/reference/configuration/basetypes#vec3">vec3</Link>} optional default="0,0,0">
A linear offset of the user position. Must define the three values `x`, `y`, and `z`.
</Parameter>

<Parameter name="matrix" type={<Link to="/docs/reference/configuration/basetypes#mat4">mat4</Link>} optional>
A generic transformation matrix that is applied to the orientation of this user. If `orientation` is specified as well, this value is ignored.
</Parameter>

<Parameter name="orientation" type={<Link to="/docs/reference/configuration/basetypes#orientation">Orientation</Link>} optional>
Describes a fixed orientation for the viewing direction of this user. This can be provided either as Euler angles or as a quaternion. This value overwrites the value specified in `matrix`.
</Parameter>

<Parameter name="tracking" type="Object" optional>
  Provides information about whether this user should be tracked using a VRPN-based tracker. This object contains two values with information about the tracker that this user should be associated with.

  <Parameter name="tracker" type="string">The name of the tracker group that this user should be linked with. This name must be a name of a [Tracker](tracker) that is specified in this configuration.</Parameter>
  <Parameter name="device" type="string">The name of the device in the tracker group that should be used to control the tracking for this user. The specified device has to be a [Device](device) that was specified in the `tracker`.</Parameter>
</Parameter>
