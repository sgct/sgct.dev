# Settings
Controls global settings that affect the overall behavior of the SGCT application that are not limited just to a single window.

## Parameters
<Parameter name="depthbuffertexture" type="boolean" optional default="false">
If this value is set to `true` and a non-linear projection method is provided in a window, SGCT will also provide a buffer containing the reprojected depth values of the non-linear projection.
</Parameter>

<Parameter name="normaltexture" type="boolean" optional default="false">
If this value is set to `true` and a non-linear projection method is provided in a window, SGCT will also provide a buffer containing the reprojected normal values of the non-linear projection.
</Parameter>

<Parameter name="positiontexture" type="boolean" optional default="false">
If this value is set to `true` and a non-linear projection method is provided in a window, SGCT will also provide a buffer containing the reprojected positions of the non-linear projection.
</Parameter>

<Parameter name="precision" type="16 or 32" optional default="32">
Determines the floating point precision for the normal and position textures if they are enabled. Setting this value if `normaltexture` and `positiontexture` are disabled does not have any effect.
</Parameter>
