# Viewport
Describes a single viewport inside a [Window](window). Every window can contain an arbitrary number of viewports that are all rendered independently. The viewports are positioned inside the window using a normalized coordinate system.

## Parameters
<Parameter name="pos" type={<Link to="/docs/reference/configuration/basetypes#vec2">vec2</Link>} optional default="0,0">
Specifies the position of the viewport inside its parent window. The coordinates for `x` and `y`, which must both be specified in this object, are usually between 0 and 1, but are not restricted. Parts of the viewport that are outside this range would lie outside the bounds of the window and are clipped. Viewports are free to overlap; they are rendered into the window in the order in which they are specified, so later viewports can overwrite previous results.
</Parameter>

<Parameter name="size" type={<Link to="/docs/reference/configuration/basetypes#vec2">vec2</Link>} optional default="1,1">
Specifies the size of this viewport inside its parent window. The coordinates for `x` and `y`, which must both be specified in this object, are usually between 0 and 1, but are not restricted. Parts of the viewport that are outside this range would lie outside the bounds of the window and are clipped. Viewports are free to overlap; they are rendered into the window in the order in which they are specified, so later viewports can overwrite previous results.
</Parameter>

<Parameter name="projection" type="Object" optional>
Defines the projection that is used to render this viewport. Must be one of:

  - [CubemapProjection](projections/cubemapprojection)
  - [CylindricalProjection](projections/cylindricalprojection)
  - [EquirectangularProjection](projections/equirectangularprojection)
  - [FisheyeProjection](projections/fisheyeprojection)
  - [PlanarProjection](projections/planarprojection)
  - [ProjectionPlane](projections/projectionplane)
  - [SphericalMirrorProjection](projections/sphericalmirrorprojection)
  - [TextureMappedProjection](projections/texturemappedprojection)

</Parameter>

<Parameter name="overlay" type="string" optional>
This value is a path to an overlay texture that is rendered on top of the viewport after the application's rendering is finished. This can be used to add logos or other static assets on top of an application. The path is relative to the location of the configuration file.
</Parameter>

<Parameter name="blendmask" type="string" optional>
This value is a path to a texture that is used as a mask to remove parts of the rendered image. The image that is provided in this should be a binary black-white image which is applied by SGCT after the application's rendering is finished. All parts where the `blendmask` image is black will be removed. The path is relative to the location of the configuration file.
</Parameter>

<Parameter name="blacklevelmask" type="string" optional>
The file referenced in this value is used as a postprocessing step for this viewport. The image should be a grayscale image, where each pixel will be multiplied with the resulting image from the application in order to perform a black level adaptation. If a pixel is completely white, the resulting pixel is the same as the application's output, if a pixel is black, the resulting pixel will be black, if it is 50% gray, the resulting pixel will be half brightness. The default is that no black level mask is applied. The path is relative to the location of the configuration file.
</Parameter>

<Parameter name="mesh" type="string" optional>
Determines a warping mesh file that is used to warp the resulting image. The application's rendering will always be rendered into a rectangular framebuffer, which is then mapped as a texture to the geometry provided by this file. This makes it possible to create non-linear or curved output geometries from a regular projection by providing the proper geometry of the surface that you want to project on. The reader for the warping mesh is determined by the file extension of the file that is provided in this value. The default is that no warping mesh is applied. The path is relative to the location of the configuration file.

Supported mesh formats, which are described in more detail on the [Mesh formats](/docs/reference/mesh-formats) page:

1. [SCISS](/docs/reference/mesh-formats#sciss) (`sgc` extension): A mesh format that was introduced by SCISS for the Uniview software. SCISS defines one mapping type for 2D warping meshes and a second for 3D cubemap lookups. SGCT only supports the 2D warping meshes, however.
1. [Scalable](/docs/reference/mesh-formats#scalable) (`ol` extension): A mesh format created by Scalable Display Technologies.
1. [SkySkan](/docs/reference/mesh-formats#skyskan) (`skyskan` or `txt` extension): A mesh format created by SkySkan.
1. [Dome Projection](/docs/reference/mesh-formats#dome-projection) (`csv` extension): A mesh format created by Dome Projection.
1. [Paul Bourke](/docs/reference/mesh-formats#paul-bourke) (`data` extension): A file format created by Paul Bourke, whose webpage also contains more information about the individual steps of the warping.
1. [Wavefront OBJ](/docs/reference/mesh-formats#wavefront-obj) (`obj` extension): The well-known textual mesh format.
1. [Portable Float Map](/docs/reference/mesh-formats#portable-float-map) (`pfm` extension): An image format storing floating point values.
1. [SimCAD](/docs/reference/mesh-formats#simcad) (`simcad` extension).
</Parameter>

<Parameter name="tracked" type="boolean" optional default="false">
Determines whether the field-of-view frustum used for this viewport should be recalculated each frame to match the window configuration. If this value is set to `false`, the field of view set in the beginning will stay unchanged. If it is `true`, it will adapt to, for example, aspect ratio changes.
</Parameter>

<Parameter name="eye" type="center, left, or right" optional>
Forces this viewport to be rendered with a specific eye, using the corresponding user's eye separation to compute the correct frustum. If this value is not set, the viewport will be rendered according to the parent window's `stereo` value.

Allowed values: `center`, `left`, `right`
</Parameter>

<Parameter name="user" type="string" optional>
The name of the [User](user) that this viewport should be linked to. If a viewport is linked to a user that has a sensor, the positions of the sensor will be automatically reflected in the user position that is used to render this viewport. The default is that the viewport is linked to the default user, which is the first user in the configuration file.
</Parameter>
