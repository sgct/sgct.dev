# ProjectionPlane
This projection method is based on providing three corner points that are used to construct a virtual image plane. The units of the positions are all relative to the user's position so are ultimately arbitrary.

## Parameters
<Parameter name="type" type="string">
Defines the type of this projection. To use the Projection Plane, this value has to be `ProjectionPlane`.
</Parameter>

<Parameter name="lowerleft" type={<Link to="/docs/reference/configuration/basetypes#vec3">vec3</Link>}>
The position of the lower left corner of the projection plane relative to the user's position. The units for these values are arbitrary.
</Parameter>

<Parameter name="upperleft" type={<Link to="/docs/reference/configuration/basetypes#vec3">vec3</Link>}>
The position of the upper left corner of the projection plane relative to the user's position. The units for these values are arbitrary.
</Parameter>

<Parameter name="upperright" type={<Link to="/docs/reference/configuration/basetypes#vec3">vec3</Link>}>
The position of the upper right corner of the projection plane relative to the user's position. The units for these values are arbitrary.
</Parameter>
