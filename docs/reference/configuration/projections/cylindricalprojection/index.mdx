# Cylindrical Projection
This projection method renders the scene into a view that can be mapped on the inside or outside of a cylinder. This projection method is supported by some live media curation tools. The forward-facing direction will be at the left border of the image unless changed via the `rotation` value.

## Parameters
<Parameter name="type" type="string">
Defines the type of this projection. To use the Cylindrical Projection, this value has to be `CylindricalProjection`.
</Parameter>

<Parameter name="quality" type={<Link to="/docs/reference/configuration/basetypes#quality">Quality</Link>} optional default="512">
Determines the pixel resolution of the cube map faces that are individually rendered to create the cylindrical rendering.
</Parameter>

<Parameter name="rotation" type="number" optional default="0">
Provides a rotation angle (in degrees) around the z-axis by which the cylindrical projection is offset in the resulting image.
</Parameter>

<Parameter name="heightoffset" type="number" optional default="0">
Offsets the height from which the cylindrical projection is generated. This is, in general, only necessary if the user position is offset and you want to counter that offset to continue producing a "standard" cylindrical projection.
</Parameter>

<Parameter name="radius" type="number" optional default="5.0">
Sets the radius of the cylinder, which is only used in the cases when stereoscopic rendering is used.
</Parameter>
