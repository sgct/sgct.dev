# Cubemap Projection
This projection type will and show the individual faces of a cube surrounding the camera. Individual cubemap faces can be toggled on and off and this projection also has the ability to share the individual cubemap faces.

## Parameters
<Parameter name="type" type="string">
Defines the type of this projection. To use the Cubemap Projection, this value has to be `CubemapProjection`.
</Parameter>

<Parameter name="quality" type={<Link to="/docs/reference/configuration/basetypes#quality">Quality</Link>} optional default="512">
Determines the pixel resolution of the cube map faces that are rendered.
</Parameter>

<Parameter name="spout" optional>
  Settings for sharing the individual cubemap faces to other applications using Spout (only on Windows).

  <Parameter name="enabled" type="boolean">Determines whether the output via Spout is enabled.</Parameter>
  <Parameter name="name" type="string" optional>The name under which Spout will share this content. If this value is not specified, a unique name will be automatically generated.</Parameter>
</Parameter>

<Parameter name="ndi" optional>
  Settings for sharing the individual cubemap faces over the local network using NDI.

  <Parameter name="enabled" type="boolean">Determines whether the output via NDI is enabled.</Parameter>
  <Parameter name="name" type="string" optional>The name under which NDI will share this content. If this value is not specified, a unique name will be automatically generated.</Parameter>
  <Parameter name="group" type="string" optional>A comma-separated list of NDI groups under which NDI will share the content. See the NDI documentation for more information.</Parameter>
</Parameter>

<Parameter name="channels" type="Object" optional>
  Controls which of the cubemaps should be rendered.

  <Parameter name="right" type="boolean">Controls the right side of the cubemap.</Parameter>
  <Parameter name="zleft" type="boolean">Controls the back side of the cubemap.</Parameter>
  <Parameter name="bottom" type="boolean">Controls the bottom side of the cubemap.</Parameter>
  <Parameter name="top" type="boolean">Controls the top side of the cubemap.</Parameter>
  <Parameter name="left" type="boolean">Controls the left side of the cubemap.</Parameter>
  <Parameter name="zright" type="boolean">Controls the front side of the cubemap.</Parameter>
</Parameter>

<Parameter name="orientation" type={<Link to="/docs/reference/configuration/basetypes#orientation">Orientation</Link>} optional>
Describes a fixed orientation for the virtual image plane. This can be provided either as Euler angles or as a quaternion.
</Parameter>
