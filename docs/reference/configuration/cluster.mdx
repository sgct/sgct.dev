# Cluster
The `Cluster` is the root object of every configuration file. It describes the entire cluster.

## Parameters
<Parameter name="version" type="integer">
The version of the configuration file format, which has to be `2`. This documentation describes version `2` of the configuration file. Files using version `1` are still accepted and are upgraded automatically when they are loaded; the only differences are that the `masteraddress` value was renamed to `serveraddress` and that the `tilt` value of the [FisheyeProjection](/docs/reference/configuration/projections/fisheyeprojection) and the [SphericalMirrorProjection](/docs/reference/configuration/projections/sphericalmirrorprojection) was replaced by their `orientation`.
</Parameter>

<Parameter name="serveraddress" type="string">
Contains the address of the node that acts as the server for this cluster. This means that one of the [Node](node) objects described in this configuration file has to have an address that corresponds to this `serveraddress`. This value can be either an IP address or a DNS name, which will be resolved at application startup.
</Parameter>

<Parameter name="nodes" type={<><Link to="/docs/reference/configuration/node">Node</Link>[]</>} optional>
Each object in this array has to be a valid [Node](node). At least one of the described nodes has to have an address that matches the cluster's `serveraddress`.
</Parameter>

<Parameter name="users" type={<><Link to="/docs/reference/configuration/user">User</Link>[]</>} optional>
Each object in this array has to be a valid [User](user). The first value in the array is considered to be the default user for the application.
</Parameter>

<Parameter name="firmsync" type="boolean" optional default="false">
Determines whether the server should frame lock and wait for all client nodes or not. It is also possible, and more advisable, to set the frame locking on an individual [Node](node) basis for the cases where not all nodes are part of a swap group. See [Synchronization](/docs/overview/synchronization) for more information.
</Parameter>

<Parameter name="threadaffinity" type="integer" optional>
Forces the thread affinity for the main thread of the application. On Windows this is achieved using the `SetThreadAffinityMask` function, but it might not be implemented on other operating systems. By default, the thread affinity is not changed.
</Parameter>

<Parameter name="scene" type={<Link to="/docs/reference/configuration/scene">Scene</Link>} optional>
Determines an overall orientation of the scene. All of its values are included in the model matrix that is passed to the rendering callbacks of the application.
</Parameter>

<Parameter name="settings" type={<Link to="/docs/reference/configuration/settings">Settings</Link>} optional>
Describes general settings for the application. The scene-specific settings can be found under the `scene` entry instead.
</Parameter>

<Parameter name="trackers" type={<><Link to="/docs/reference/configuration/tracker">Tracker</Link>[]</>} optional>
Each object in this array describes a VRPN tracker.
</Parameter>

<Parameter name="generator" type="Object" optional>
  Information about the generator application that was used to create the configuration file.

  <Parameter name="name" type="string">A human-friendly name for the generator that created this configuration file.</Parameter>

  <Parameter name="major" type="integer">The major version of the generator that created this configuration file.</Parameter>

  <Parameter name="minor" type="integer">The minor version of the generator that created this configuration file.</Parameter>
</Parameter>

<Parameter name="meta" type="Object" optional>
  Information and description of the configuration file.

  <Parameter name="name" type="string">Name of the configuration file.</Parameter>

  <Parameter name="description" type="string">Description of the configuration file.</Parameter>

  <Parameter name="author" type="string" optional documentation="Author's name." />

  <Parameter name="license" type="string" optional documentation="Details of the software license." />

  <Parameter name="version" type="string" optional documentation="Version number of the configuration file's contents." />
</Parameter>
