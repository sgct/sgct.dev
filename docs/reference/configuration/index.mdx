# Configuration files
The format for the SGCT configuration files is JSON that defines the entire [Cluster](cluster) containing one or more [Node](node) objects, one or more [User](user) objects, and the optional [Scene](scene), [Settings](settings), [Capture](capture), and [Tracker](tracker) objects. Each of the components in the configuration files is described on its own page. Each configuration file has to fulfill the JSON schema which can be found in the [SGCT repository](https://raw.githubusercontent.com/sgct/sgct/master/sgct.schema.json).

This is an example of a single node configuration file. For more examples, check out the `config` folder that comes with SGCT or the [Examples](/docs/examples) section in this documentation.
