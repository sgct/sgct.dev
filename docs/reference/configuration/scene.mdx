# Scene
Determines an overall orientation of the scene. It consists of an `offset`, an `orientation`, and a `scale`; all of which are combined into the `modelMatrix` (and thus the `modelViewProjectionMatrix`) of the [`RenderData`](/docs/overview/how-it-works#draw) that is passed to the rendering callbacks of the application. A common use-case in planetariums, for example, is to account for a tilt in the display system by providing an `orientation` aligning with the planetarium surface. This makes it possible to reuse the same application between the planetarium dome and fixed setups without the need for special care.

## Parameters
<Parameter name="offset" type={<Link to="/docs/reference/configuration/basetypes#vec3">vec3</Link>} optional default="0,0,0">
A linear offset of the scene center. Must define the three values `x`, `y`, and `z`.
</Parameter>

<Parameter name="orientation" type={<Link to="/docs/reference/configuration/basetypes#orientation">Orientation</Link>} optional>
Describes a fixed orientation of the global scene.
</Parameter>

<Parameter name="scale" type="number" optional default="1.0">
A scaling factor for the entire scene.
</Parameter>
