# Node
Defines a single computing node that is contained in the described cluster. In general this corresponds to a single computer, but it is also possible to create multiple nodes on a local machine by using the `127.0.0.x` IP address with x from `0` to `255`. It is not possible to create multiple nodes on the same remote computer, however.

## Parameters
<Parameter name="address" type="string">
The IP address or the DNS name of the node. If the address is a DNS name, the name resolution is delegated to the operating system and might include additional network traffic to the DNS host. If the node ought to be the local machine either `127.0.0.x` with x from `0` to `255`, or `localhost` (which corresponds to `127.0.0.1`) can be used.
</Parameter>

<Parameter name="port" type="integer">
The port at which this node is available to the server. Please note that operating systems have restricted behavior when trying to open ports lower than a fixed limit. For example, Unix does not allow non-privileged users to open ports \< 1024. As a convention, SGCT usually uses ports starting at 20400.
</Parameter>

<Parameter name="datatransferport" type="integer" optional>
If this value is set, a socket connection is opened at the provided port that can be used by the application to transmit data between the server and the clients. If no value is specified these data transfer functions will not work. Please note that operating systems have restricted behavior when trying to open ports lower than a fixed limit. For example, Unix does not allow non-privileged users to open ports \< 1024.
</Parameter>

<Parameter name="swaplock" type="boolean" optional default="false">
Determines whether this node should be part of an NVIDIA swap group and should use the swap barrier. Please note that this feature only works on Windows and requires professional NVIDIA graphics cards that are connected with NVIDIA sync cards. It also requires [`vsync`](#vsync) to be enabled; otherwise SGCT logs a warning. See [Synchronization](/docs/overview/synchronization#swap-lock) for more information on swap groups.
</Parameter>

<Parameter name="vsync" type="boolean" optional default="false">
Determines whether this node synchronizes its buffer swaps with the vertical retrace of the monitor (V-Sync), which limits the frame rate to the refresh rate of the monitor. As the windows of a node swap their buffers one after another, only the last window of the node waits for the vertical retrace; waiting in every window would divide the frame rate by the number of windows. See [Synchronization](/docs/overview/synchronization#v-sync) for how V-Sync interacts with the synchronization of the cluster.
</Parameter>

<Parameter name="windows" type={<><Link to="/docs/reference/configuration/window">Window</Link>[]</>} optional>
Specifies windows that are used to render content into. There can be an arbitrary(-ish) number of windows for each node and they all will be created and initialized at start time. Each window has at least one [Viewport](viewport) that specifies exactly where in the window the rendering occurs with which parameters.
</Parameter>
