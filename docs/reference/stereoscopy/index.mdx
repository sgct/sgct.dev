# Stereoscopy
This page contains all of the different stereoscopic rendering methods supported by SGCT. The method is selected with the [`stereo`](/docs/reference/configuration/window#stereo) value of a window, and the distance between the eyes is determined by the `eyeseparation` of the [User](/docs/reference/configuration/user). Each example shows the configuration file that selects the method and the image that the [Calibrator](/docs/building/calibrator) application renders with it.

## Active
Active stereo (`active`, or its alias `quadbuffer`) renders the left and right eye images into separate back buffers of a quad-buffered OpenGL context. Displaying them requires a graphics card, driver, and display that support quad-buffered stereo, which are typically used together with shutter glasses. As the eyes are shown alternately by the display, there is no single image that could be shown here.

## Checkerboard
<Example json={checkerboard_json} file="checkerboard.json" image={checkerboard_image}>
The left and right eye images are interleaved in a checkerboard pattern, in which neighboring pixels alternate between the eyes. This format is used by DLP projectors and displays.
</Example>
